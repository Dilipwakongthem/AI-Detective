## 🎯 Difficulty System

### Available Difficulties:

1. **Easy Mode**
   - 3-5 suspects
   - 6-10 evidence pieces
   - 0-1 red herrings
   - Clear hints
   - Ideal for beginners

2. **Normal Mode** (Default)
   - 5-8 suspects
   - 10-15 evidence pieces
   - 1-3 red herrings
   - Balanced challenge

3. **Hard Mode**
   - 8-12 suspects
   - 15-20 evidence pieces
   - 3-5 red herrings
   - Subtle clues
   - Expert deduction required

4. **Cold Case Mode**
   - 6-10 suspects
   - 12-18 evidence pieces
   - 2-4 red herrings
   - Aged evidence
   - 10-30 years old
   - Methodology scoring

### Difficulty Selection:
- Procedural cases: Based on your rank
- Hand-crafted cases: Pre-set difficulty (shown in library)
- Cold cases: Always "Cold Case" difficulty
- Tutorials: Easy difficulty

## 🎮 Gameplay Flow

### Recommended Path for New Players:

1. **Start Tutorial** (Case Library → Tutorials → The Missing Wallet)
2. **Play Hand-Crafted Cases** (Case Library → Hand-Crafted → Start with "The Stolen Manuscript")
3. **Try Cold Cases** (Case Library → Cold Cases → Any case)
4. **Use Evidence Board** (During investigation → Opens new deduction paths)
5. **Use Notebook** (Track theories, build timelines, profile suspects)
6. **Experiment with Interrogation** (Try different approaches with suspects)
7. **Challenge Yourself** (Hard mode or procedural cases)

### Pro Tips:
- 💡 Use the Evidence Board for complex cases
- 💡 Build theories in the Notebook before accusing
- 💡 Try different interrogation approaches - each suspect responds differently
- 💡 Cold cases require modern forensic thinking applied to old evidence
- 💡 Tutorial cases teach specific skills - replay to practice
- 💡 Hand-crafted cases have multiple solution paths
- 💡 Check the Case Library regularly for new content
